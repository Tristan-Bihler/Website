## Idee & Motivation

Ich wollte einen zentralen Ort, an dem ich meine Projekte und Reisen dokumentieren kann –
ohne kompliziertes CMS, dafür mit voller Kontrolle über Design und Inhalt.

Die Wahl fiel auf **Jekyll** mit **GitHub Pages**, weil:
- kein Server notwendig
- Inhalte als Markdown schreibbar
- kostenfreies Hosting
- eigene Domain einfach einbindbar

## Umsetzung

Das Farbschema orientiert sich an warmen Tönen: **Orangerot**, **Schwarz** und **Cremeweiß**.
Das Ziel war eine Seite, die sich persönlich und einladend anfühlt.

```scss
:root {
  --cream:  #F5ECD7;
  --orange: #D4621A;
  --dark:   #2B1E0E;
}
```

- SCSS-Variablen für konsistentes Design
- GitHub Pages Deployment mit Custom Domain
