## Über das Projekt

Diese Website ist mein persönliches Portfolio, auf dem ich Projekte, Blog-Artikel und Fotos teile.

## Technologien

- **Next.js 16** — React Framework mit App Router
- **TypeScript** — Typsicherheit
- **Tailwind CSS** — Utility-First Styling

## Features

- Dynamische Projektseiten aus Markdown-Dateien
- Bildergalerie mit Lightbox
- Parallax-Hero-Bereich
- Dunkles Farbschema (Charcoal & Amber)

## Was ich gelernt habe

Das Projekt hat mir gezeigt, wie man mit Next.js Server Components und dem Dateisystem arbeiten kann, um statische Inhalte dynamisch zu rendern.
